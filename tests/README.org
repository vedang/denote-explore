#+title: Denote Explorer test setup

* Emacs dependencies
Requires Emacs >=29.1 and Python 3. Dependencies live only in ignored
=tests/.deps/=. No personal init file, package directory, or notes are used.
=deps-lock.json= pins upstream revisions/versions and SHA-256 archive checksums:
Denote 4.2.3, denote-sequence 0.3.3, dash 2.20.0, denote-regexp 20250415.2202.
Existing package metadata lists dash >=2.19.1, but source already uses
=-frequencies= introduced in 2.20.0; this harness pins the compatible version.
Downloaded package files retain upstream license notices. Setup needs network;
subsequent test runs do not. Set =DENOTE_EXPLORE_TEST_DEPS= for another cache,
and =EMACS= for another executable. Local validation used Emacs 30.2.

#+begin_src sh
python3 tests/setup-deps.py
sh tests/run-ert.sh
sh tests/run-ert.sh '"denote-explore-smoke"'
emacs --batch -Q -l tests/bootstrap.el -l tests/check-lisp.el
#+end_src

The optional selector is an Emacs Lisp expression. Smoke tests cover real
=numeric= (1=2=3) and =alphanumeric= (1b3) split/join behavior and simulate
absence of optional denote-sequence without affecting other graph functions.
Every feature test must use temporary synthetic notes and restore dynamic
settings. Bootstrap creates and deletes an otherwise empty temporary note root.

No Makefile exists. Syntax/byte compilation and ERT are native alternatives
to unavailable =make format=, =make check=, and =make test=. Byte-compiled
artifacts go under ignored =tests/artifacts/=, never alongside package source.
Use =check-parens= and review formatting rather than mass-reformatting source.

* Controlled browser
Node >=20, npm, and the pinned Playwright Chromium binary are required.
#+begin_src sh
npm --prefix tests ci --ignore-scripts
PLAYWRIGHT_BROWSERS_PATH="$PWD/tests/.deps/browsers" npm exec --prefix tests -- playwright install chromium
sh tests/run-browser.sh smoke
sh tests/run-browser.sh
#+end_src
Optional first argument is a JavaScript test-name regexp. =TASK_DIR= may name an
existing task folder for screenshots; otherwise the runner creates a timestamped
folder under ignored =.agents/plans/=. No personal Chrome, note directory or
network access is used during tests. Setup alone downloads dependencies.

=package-lock.json= pins archive integrity and versions (D3 7.9.0, Playwright
1.58.2; Chromium 145.0.7632.6). D3 source https://github.com/d3/d3, installed
from npm package =d3=; upstream LICENSE remains in =node_modules/d3/LICENSE=.
SHA-256 of =d3/dist/d3.min.js=:
=f2094bbf6141b359722c4fe454eb6c4b0f0e42cc10cc7af921fc158fceb86539=.

Harness serves actual =denote-explore-network.html= after its real placeholders
are replaced. Test-only wrapper seeds/stops simulation and exposes existing
bindings; it does not copy application logic or add production test hooks.
Popup calls and top-level navigation are trapped separately from canned hover
iframe requests. Every test captures JS errors and a 1280x800 screenshot.
=[ref:sequence_hero_identity]= fixture/radius/framing rubric lives in
=sequence-context-contract.org=.

* Browser selector ownership
Run =sh tests/run-browser.sh 'PREFIX:'= (alternatives separated by =|=):
- =normalize:= task15; =paths:= task16; =hero:= task17; =framing:= task18.
- =focus:= task19 (6 named cases).
- =camera:= (4, including clear-pan regression) and =drag:= (1) task20.
- =labels:= (6: nonzero priorities, zero density across four graph types,
  equal-degree range); =isolation:= (1), extending task21.
- =sidebar:= (4: selected details and node/edge preview fallback across graph types).
- =keyboard:= (6, including animated Enter/Space), =status:= (1),
  =reduced-motion:= (1) task22.
- =statistics:= task23.
Node may print a passing file wrapper for files with no matching tests; these
are not additional assertion cases. Full integration runs every group.
Tests use existing node/link selections; =.sequence-halo= names persistent
sequence rings. Keyboard/status cases require standard roles and aria-live,
not a separate production test API.

* GraphViz syntax/render gate
#+begin_src sh
node tests/check-graphviz.mjs
#+end_src
Uses checksum-locked =@viz-js/viz= 3.30.0 (GraphViz 16.0.0 compiled to WASM) to
parse/render DOT emitted by the actual Lisp encoder. This supplies an actual
GraphViz-engine check when system =dot= is unavailable; it does NOT install or
replace the production =dot= executable. Production GraphViz viewing still
requires =dot= on PATH. Set =DENOTE_EXPLORE_TEST_ARTIFACTS= to a task-folder path
for emitted DOT/SVG evidence. Tests retain GraphViz hyperlinks and every typed,
parallel, reciprocal and self-edge record.

* Real-export and representative performance validation
#+begin_src sh
sh tests/run-browser.sh 'integration:'
DENOTE_EXPLORE_TEST_ARTIFACTS="$TASK_DIR/performance" node tests/probe-performance.mjs
#+end_src
The integration fixture creates real temporary Denote notes, calls actual Lisp
JSON and HTML exporters with browser launch stubbed, and serves that exact HTML.
It parses substituted JS and checks focus/data/statistics, not copied UI logic.
The standalone performance probe uses 1200 real notes (depth2 star/ring) plus the
fixed dense-hub fixture. It records counts, one extractor scan, generation/load/
settling/focus timings, finite geometry, sizing bounds and screenshots. Settling
waits for the real simulation end event and verifies all sequence members remain
inside the viewport; it does not stop a still-cooling layout. Override
=PERFORMANCE_NOTE_COUNT= only within 5..5000. Timings exclude fixture creation
and are machine-local observations, not universal latency claims. Direct harness
imports default to the pinned local browser cache too.

* Distributed manuals
From the repository root, regenerate (never hand-edit) the distributed manuals:
#+begin_src sh
emacs --batch -Q --eval '(progn (require (quote org)) (require (quote ox-texinfo)) (find-file "denote-explore.org") (org-texinfo-export-to-texinfo))'
makeinfo --no-split --output=denote-explore.info denote-explore.texi
#+end_src
Verified with Emacs 30.2, bundled Org 9.7.11 / ox-texinfo, and GNU Texinfo 7.3.
Repeat export must leave both files byte-identical with these versions. Other
versions may reflow output; inspect such changes separately from content edits.
Explicit Org =#+author= preserves existing Peter Prevos credit independently of
=user-full-name=. Validation also checks unique nodes, resolving menu targets,
and matching Texinfo/Info node sets.
